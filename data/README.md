# Data Notes

This project uses the Telco Customer Churn dataset.

The raw dataset contains 7,043 customer records and 21 columns, including customer demographics, account information, service subscriptions, charges, and churn status.

The raw CSV is not included in this repository if redistribution rights are unclear. The notebook documents the full validation, cleaning, feature engineering, exploratory analysis, and modeling workflow.

The cleaned dataset was exported locally for Power BI dashboarding.
